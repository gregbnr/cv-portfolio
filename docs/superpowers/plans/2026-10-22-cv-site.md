# CV Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire le site CV single-page bilingue (FR/EN) de Grégoire Bonnier en Astro statique, style « violet néon », avec apps en mockups téléphone et contact via `mailto`.

**Architecture:** Site Astro à sortie statique. Tout le contenu vit dans `src/data/{fr,en}.ts` (typé) ; les pages `index.astro` (FR) et `en/index.astro` (EN) assemblent des composants `.astro` présentationnels alimentés par la locale courante. Le seul morceau de logique testé unitairement est `src/lib/mailto.ts`. Les animations au scroll sont un enrichissement progressif (contenu visible par défaut).

**Tech Stack:** Astro (dernière stable), TypeScript, CSS natif (design tokens + `light-dark()`), Vitest (test unitaire), polices auto-hébergées. Aucun back-end.

**Spec:** `docs/superpowers/specs/2026-10-22-cv-site-design.md`

## Global Constraints

- **Astro** dernière version stable, `output: 'static'`. TypeScript strict.
- **i18n :** locales `['fr','en']`, `defaultLocale: 'fr'`. FR à `/`, EN à `/en/`.
- **CSS natif** uniquement (design tokens en custom properties). Pas de framework CSS lourd, pas de dépendance runtime JS lourde.
- **Email de contact (verbatim) :** `gmfbonnier.pro@gmail.com`.
- **Badges stores (verbatim) :** « Play Store » et « App Store » (en toutes lettres).
- **Animations :** uniquement `opacity` / `transform` ; `prefers-reduced-motion: reduce` respecté au cas par cas ; scroll-driven sous `@supports ((animation-timeline: view()) and (animation-range: entry))`.
- **Thème :** sombre par défaut, `color-scheme` + `light-dark()`, choix mémorisé en `localStorage`, script anti-FOUC inline.
- **Accessibilité :** WCAG AA (contrastes inclus), HTML sémantique, navigation clavier, `:focus-visible`.
- **Perf :** objectif Lighthouse ≥ 95 (mobile & desktop).
- **Polices auto-hébergées**, `font-display: swap`.

## Review Focus

- **Firefox (pas de scroll-driven animations)** — tout le contenu doit rester visible et lisible (animations décoratives seulement). → couvert Task 13.
- **`prefers-reduced-motion: reduce`** — les reveals/gradients animés se coupent sans casser la mise en page. → couvert Task 13.
- **Client mail par défaut absent / non configuré** — le bouton « Copier l'email » et le lien LinkedIn offrent une alternative fonctionnelle. → couvert Task 11.
- **Largeur mobile étroite (~320px) & contenu long** — aucun débordement horizontal, nav repliée utilisable. → couvert Task 14.
- **Thème au tout premier paint (no-FOUC)** — le thème mémorisé/préféré s'applique avant le premier rendu, sans flash clair→sombre. → couvert Task 1.

```ts
import { buildMailto } from './mailto';

describe('buildMailto', () => {
  it('encode objet et corps dans l’URL mailto', () => {
    const url = buildMailto('gmfbonnier.pro@gmail.com', 'Offre & poste', 'Bonjour,\nContact via le site?');
    expect(url).toBe(
      'mailto:gmfbonnier.pro@gmail.com?subject=Offre%20%26%20poste&body=Bonjour%2C%0AContact%20via%20le%20site%3F'
    );
  });

  it('gère objet et corps vides', () => {
    expect(buildMailto('a@b.com', '', '')).toBe('mailto:a@b.com?subject=&body=');
  });
});
```
